添加课程

从正方教务导入

  1. 用电脑浏览器登录你学校的正方教务系统（网址里通常有 jwglxt），停留在登录后的任意页面。
  2. 按 F12 打开开发者工具 → 切到「控制台 / Console」。
  3. 点下面的「复制脚本」，粘贴到控制台回车（Chrome 首次粘贴可能要求先输入 allow pasting）。
  4. 脚本会自动下载 正方课表_学年_学期.json 并尝试复制到剪贴板。
  5. 回到本页「② 粘贴 / 上传」，选择该文件或直接粘贴即可。

      

      

        用书签（Bookmarklet）方式
        
把下面这个链接拖到书签栏（或新建书签并把网址改成复制的内容），登录正方后点击该书签即可。手机浏览器可新建书签，网址粘贴后在正方页面地址栏输入书签名触发。

        
📅 导出正方课表 

      

      

        手动从开发者工具拿 JSON
        
在正方「信息查询 → 学生课表查询」页选好学年学期点查询，F12 → 网络(Network) 中找到 xskbcx_cxXsgrkb.html（部分学校为 xskbcx_cxXsKb.html）请求，复制「响应」全文粘贴到 ② 即可。
